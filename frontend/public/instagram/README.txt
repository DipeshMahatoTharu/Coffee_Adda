Coffee Adda - Instagram Photos Guide
======================================
You can put your exact Instagram post photos here!

Just save 6 images into this folder with these exact filenames:
- post-1.jpg (Signature Latte Art)
- post-2.jpg (The Budhanilkantha Haven / Cafe ambiance)
- post-3.jpg (Himalayan Mo:Mo & Khaja)
- post-4.jpg (Barista Espresso Extraction)
- post-5.jpg (House-Baked Croissants / Bakery)
- post-6.jpg (Warm Community Adda)

If any file is missing, the website will automatically display the high-resolution authentic fallback image.

To link each card directly to a specific Instagram post URL (e.g., https://www.instagram.com/p/Cxyz123/):
Open `src/components/InstagramFeed.jsx` and replace `postUrl` for that item.
